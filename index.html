03 ZERO FRICTION SETUP FIG. 05

Integrate into GitHub Actions in 60 seconds.

Add GateKeeper to your repository's workflow to automatically scan every pull request before dependencies are installed into your build agents.

POLICY2 SETTINGS
  • Automated GitHub security report artifact generation
  • Zero external agent installation required
  • Configurable threshold blocking policies
.GITHUB/WORKFLOWS/SECURITY.YML 
name: Security Audit Pipeline
on: [push, pull_request]

jobs:
  gatekeeper-scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: GateKeeper Supply Chain Scan
        uses: Swan/gatekeeper@v1
        with:
          requirements-file: 'requirements.txt'
          fail-on-severity: 'CRITICAL'
          skip-sandbox: 'true'
